CHAOS

The first database of first-principles calculations dedicated to high-entropy oxides.

Combinatorial High-throughput Analysis and Optimization for Synthesis. Each disordered oxide is represented by an ensemble of relaxed density functional theory (DFT) supercells and connected to its ordered binary and ternary reference oxides, so the information available from composition alone can be compared with structural and thermodynamic information from explicit calculations.

Contents

Ensembles of relaxed supercells

Chemical disorder is represented by the symmetrically distinct supercells that reproduce each composition's site occupancies. Every supercell is relaxed with DFT and counted by its degeneracy, so each composition carries a distribution of enthalpies and relaxed structures. The rocksalt systems have between {{ n("oxide.rocksalt_supercells_min", ox.rocksalt_supercells_min) }} and {{ n("oxide.rocksalt_supercells_max", ox.rocksalt_supercells_max) }} supercells each, typically {{ n("oxide.rocksalt_supercells_median", ox.rocksalt_supercells_median) }}.

Formability and disorder descriptors

The spread of the supercell enthalpies, weighted by degeneracy, gives a formability descriptor: a narrow spread means many configurations lie close in enthalpy. The relaxed supercells give the lattice distortion and the root-mean-square atomic displacement, averaged with Boltzmann weights at 300 K. These, with the atomic-solubility parameter, configurational entropy, valence electron concentration and the Miedema mixing enthalpy, are stored for the disordered systems and can be used as filters in API queries.

Ordered reference oxides

The ordered binary and ternary oxides are calculated at the same level of theory, so each disordered system can be compared with the ordered phases that compete with it. For the {{ n("oxide.coverage_systems", ox.coverage_systems) }} disordered systems whose only anion is oxygen (the other {{ n("derived.mixed_anion", ox.mixed_anion_systems) }} also contain another anion), all {{ n("oxide.coverage_one_cation.1", ox.coverage_one_cation[1]) }} single-cation oxides and {{ n("oxide.coverage_two_cation.0", ox.coverage_two_cation[0]) }} of {{ n("oxide.coverage_two_cation.1", ox.coverage_two_cation[1]) }} two-cation oxide systems have ordered entries.

Charges and volumes per atom

Bader charges and atomic volumes are stored for {{ n("bader_atoms", st.bader_atoms) }} atoms, including the {{ n("oxide.supercell_atoms_with_bader", ox.supercell_atoms_with_bader) }} atoms inside the disordered oxide supercells.

The DFT calculations use the Perdew–Burke–Ernzerhof (PBE) generalized-gradient functional. Configurational entropy, valence electron concentration and the Miedema mixing enthalpy are computed from the composition. Counts are for the public database as of {{ data.chaos.as_of_text }}. An entry is one calculation: an ordered structure, one supercell of an ensemble, or one disordered system.

Access

CHAOS is available to registered users. Create an account and confirm your email address from the message you receive; the S4E Laboratory then approves the account. If you already have an account, sign in.

API access

The REST API serves the database entries and descriptors to signed-in users. Scripts send a LOOP API key in the X-API-Key header; create one under Developers after signing in. Documentation and examples: s4e.ai/API/chaos/?help.

CHAOS-Agent

A natural-language interface to the database. After signing in, open CHAOS-Agent.
