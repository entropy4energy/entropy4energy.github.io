CHAOS

The first database of first-principles calculations dedicated to high-entropy oxides.

CHAOS stands for Combinatorial High-throughput Analysis and Optimization for Synthesis. Each disordered oxide is represented by an ensemble of relaxed density functional theory (DFT) supercells and linked to its ordered binary and ternary reference oxides. This connects composition-based descriptors with structural and thermodynamic quantities from explicit calculations.

Contents

Ensembles of relaxed supercells

Chemical disorder is represented by the symmetrically distinct supercells that reproduce each composition's site occupancies. Every supercell is relaxed with DFT and weighted by its degeneracy, giving a distribution of enthalpies and relaxed structures for each composition. The rocksalt systems have between {{ n("oxide.rocksalt_supercells_min", ox.rocksalt_supercells_min) }} and {{ n("oxide.rocksalt_supercells_max", ox.rocksalt_supercells_max) }} supercells each, typically {{ n("oxide.rocksalt_supercells_median", ox.rocksalt_supercells_median) }}. Each system page gives the number of supercells and their enthalpy spread.

Formability and disorder descriptors

The formability descriptor is the inverse of the degeneracy-weighted spread (standard deviation) of the supercell enthalpies; a narrow spread means many configurations lie close in enthalpy. The relaxed supercells give the lattice distortion and the root-mean-square atomic displacement, averaged with Boltzmann weights at 300 K. CHAOS also stores the atomic-solubility parameter, configurational entropy, valence electron concentration and Miedema mixing enthalpy for the disordered systems. These quantities can be used directly in API queries. Each system page shows the formability, lattice distortion, atomic displacement, size and electronegativity mismatch and valence electron concentration with their percentiles in the system's cohort. The compatibility score, SCHAOS, is the mean of a distortion part and a chemistry part built from the descriptor percentiles.

Ordered reference oxides

The ordered binary and ternary oxides are calculated at the same level of theory and provide the reference phases for each disordered system. For the {{ n("oxide.coverage_systems", ox.coverage_systems) }} disordered systems whose only anion is oxygen (the other {{ n("derived.mixed_anion", ox.mixed_anion_systems) }} also contain another anion), all{{ n("oxide.coverage_one_cation.0", one[0]) }} of {{ n("oxide.coverage_one_cation.1", one[1]) }} single-cation oxides and {{ n("oxide.coverage_two_cation.0", ox.coverage_two_cation[0]) }} of {{ n("oxide.coverage_two_cation.1", ox.coverage_two_cation[1]) }} two-cation oxide systems have ordered entries. Each system page lists its end members and two-cation compounds; every ordered entry is available through the API and CHAOS-Agent.

Charges and volumes per atom

Bader charges and atomic volumes are stored for {{ n("bader_atoms", st.bader_atoms) }} atoms.

Properties

{# What each kind of entry holds. The kinds are counted in the tiles at the top; counts appear here only for values some entries lack. #}

Each disordered oxide system

  • Formability, in (eV/atom)⁻¹
  • Formation enthalpy, the degeneracy-weighted mean over its supercells, in eV/atom
  • Lattice distortion at 0 and 300 K
  • Root-mean-square atomic displacement at 0 and 300 K, in Å
  • Atomic-solubility parameter at 0 and 300 K, in GPa Å³
  • Configurational entropy, in kB/atom
  • Valence electron concentration, in e/atom
  • Miedema mixing enthalpy, in eV/atom

Each ordered oxide

  • Relaxed structure and space group
  • Formation enthalpy, in eV/atom
  • Bader charges and atomic volumes, in e, Å³

Access

CHAOS is available to registered users. Create an account, confirm your email address, and wait for S4E Laboratory approval. If you already have an account, sign in.

API

The REST API provides database entries and descriptors to authenticated users. Scripts authenticate with a LOOP API key in the X-API-Key header; keys are created under Developers after signing in. Documentation and examples: s4e.ai/API/chaos/?help.
