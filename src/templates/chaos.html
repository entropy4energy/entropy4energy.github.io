CHAOS

Combinatorial High-throughput Analysis and Optimization for Synthesis: a first-principles database of high-entropy oxides, their ordered binary and ternary precursors, and a library of structural and chemical descriptors for synthesis-oriented screening.

Access API Chaos-Agent
Account
Create an account, then sign in to use the API and Chaos-Agent.
API
Query entries and descriptors over HTTP from scripts and notebooks.
Chaos-Agent
Ask questions in plain language; the agent turns them into database retrievals.

Access

CHAOS is available to registered users. Create an account and confirm your email address from the message you receive; the S4E Laboratory then approves the account. If you already have an account, sign in.

API access

The REST API serves the database entries and descriptors to signed-in users. Scripts send a LOOP API key in the X-API-Key header; create one under Developers after signing in. Documentation and examples: s4e.ai/API/chaos/?help.

Chaos-Agent

A natural-language interface to the database, in the browser. After signing in, open Chaos-Agent.
